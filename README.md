# Gharko Swad Monorepo

Gaunle Swad is a cloud kitchen and food delivery application ecosystem consisting of four distinct React frontends (Customer, Admin, Kitchen, Rider) and a robust Node.js/Express backend. 

The system relies on a monolithic codebase structure with shared components, an integrated API, and a unified authentication architecture to provide seamless operation from order placement to delivery execution.
